직접 강도 명령은 약 1초 후 자동 종료될 수 있습니다. 슬라이더를 움직여도 전송되지 않으며, 버튼을 눌러야 명령이 전송됩니다.

긴급 정지

패턴 OFF 및 직접 강도 0 명령을 순차 전송합니다. BLE 연결이 끊어져 있거나 기기가 명령에 응답하지 않는 경우 정지를 보장할 수 없습니다. 기기 자체 전원 버튼도 사용하세요.

BLE 통신 로그

TX: 앱에서 송신한 HEX / RX: 기기에서 수신한 HEX. 연결 이후에만 명령을 보낼 수 있습니다.

시제품 · 데이터는 이 페이지 안에서만 처리합니다. 연결하려면 iOS에서는 Bluefy 등 Web Bluetooth 지원 브라우저를 이용하고, HTTPS 주소로 열어주세요. 화면 잠금/백그라운드 상태에서는 BLE 동작이 지속된다고 보장할 수 없습니다.
